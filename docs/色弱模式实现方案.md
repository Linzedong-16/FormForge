# 问卷系统色弱模式实现方案

## 1. 需求分析

### 1.1 目标用户群体

| 用户类型 | 特征描述 | 需求优先级 |
|---------|---------|-----------|
| **红绿色盲** | 无法区分红色和绿色，最常见的色弱类型 | 高 |
| **蓝色盲** | 无法区分蓝色和黄色 | 中 |
| **全色盲** | 只能看到黑白灰 | 低 |
| **色弱人群** | 颜色辨别能力较弱，但不完全丧失 | 高 |
| **普通用户** | 可能在特定场景下（如强光/弱光环境）需要高对比度模式 | 中 |

**统计数据**：全球约8%的男性和0.5%的女性存在不同程度的色弱问题。

### 1.2 使用场景分析

| 场景 | 描述 | 影响程度 |
|------|------|---------|
| **问卷编辑** | 使用颜色区分不同题型、状态 | 高 |
| **数据可视化** | 图表颜色编码信息 | 高 |
| **表单验证** | 红色错误提示、绿色成功提示 | 中 |
| **导航菜单** | 选中/未选中状态的颜色区分 | 中 |
| **按钮交互** | 悬停/点击状态的颜色反馈 | 低 |

### 1.3 功能要求

| 功能点 | 描述 | 必要性 |
|--------|------|-------|
| **色弱模式切换** | 用户可手动切换到色弱友好模式 | 必需 |
| **自动检测** | 可检测系统色弱设置并自动适配 | 建议 |
| **多种色弱类型** | 支持红绿色盲、蓝色盲等多种模式 | 必需 |
| **持久化存储** | 用户选择自动保存 | 必需 |
| **全局生效** | 色弱模式对所有组件生效 | 必需 |

## 2. 技术实现方案

### 2.1 色彩调整策略

#### 2.1.1 色弱类型与配色方案

| 色弱类型 | 问题描述 | 调整策略 |
|---------|---------|---------|
| **Protanopia（红色盲）** | 缺少红色感光细胞 | 避免使用红色作为唯一区分色 |
| **Deuteranopia（绿色盲）** | 缺少绿色感光细胞 | 避免使用绿色作为唯一区分色 |
| **Tritanopia（蓝色盲）** | 缺少蓝色感光细胞 | 避免使用蓝色作为唯一区分色 |

### 2.2 实现方法

#### 2.2.1 状态管理

```typescript
// stores/useColorBlind.ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export type ColorBlindMode = 'normal' | 'protanopia' | 'deuteranopia' | 'tritanopia' | 'achromatopsia';

export const useColorBlindStore = defineStore('colorBlind', () => {
// 当前色弱模式
const mode = ref<ColorBlindMode>('normal');

// 是否启用色弱模式
const isEnabled = computed(() => mode.value !== 'normal');

// 设置色弱模式
const setMode = (newMode: ColorBlindMode) => {
    mode.value = newMode;
    localStorage.setItem('colorBlindMode', newMode);
    // 触发主题更新
    document.documentElement.setAttribute('data-color-blind', newMode);
};

// 从本地存储恢复
const loadMode = () => {
    const saved = localStorage.getItem('colorBlindMode') as ColorBlindMode | null;
    if (saved && ['normal', 'protanopia', 'deuteranopia', 'tritanopia', 'achromatopsia'].includes(saved)) {
    mode.value = saved;
    document.documentElement.setAttribute('data-color-blind', saved);
    }
};

return {
    mode,
    isEnabled,
    setMode,
    loadMode,
};
});
```
