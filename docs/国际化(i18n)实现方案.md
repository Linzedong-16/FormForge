### 2.1 候选插件对比

| 插件 | 版本 | 星数 | 功能特性 | 性能 | 社区支持 |
|------|------|------|---------|------|---------|
| **vue-i18n** | 9.x | 7.8k | 官方方案、Composition API、支持TypeScript | 优秀 | 活跃 |
| **vue-intl** | 2.x | 1.8k | 基于Format.js、ICU消息格式 | 良好 | 中等 |

### 2.2 推荐方案：vue-i18n

**推荐理由：**

1. **官方支持**：Vue 官方国际化解决方案，与 Vue 3 深度集成
2. **Composition API**：完美支持 Vue 3 的 Composition API 风格
3. **TypeScript 友好**：提供完整的类型定义
4. **性能优异**：支持懒加载、缓存机制
5. **生态完善**：与 Element Plus 无缝配合

### 3.3 步骤三：配置 i18n 实例

**文件：** `src/locales/index.ts`

```typescript
import { createI18n } from 'vue-i18n';
import type { App } from 'vue';

// 动态导入翻译文件
const loadLocaleMessages = () => {
  const locales = import.meta.glob('./**/*.ts', { eager: true });
  const messages: Record<string, Record<string, string>> = {};
  
  for (const path in locales) {
    const locale = path.split('/')[1]; // zh-CN, en-US, ja-JP
    const module = locales[path] as { default: Record<string, string> };
    
    if (!messages[locale]) {
      messages[locale] = {};
    }
    
    // 获取文件名（不含扩展名）作为命名空间
    const namespace = path.split('/').pop()?.replace('.ts', '') || 'common';
    messages[locale][namespace] = module.default;
  }
  
  return messages;
};

export const i18n = createI18n({
  legacy: false,           // 使用 Composition API
  locale: 'zh-CN',         // 默认语言
  fallbackLocale: 'en-US', // 回退语言
  messages: loadLocaleMessages(),
});

export const setupI18n = (app: App) => {
  app.use(i18n);
};
```

### 3.4 步骤四：更新 main.ts 集成 i18n

```typescript
// Element Plus
import ElementPlus from 'element-plus';
import { zhCn, en, ja } from 'element-plus/es/locales.mjs';
import 'element-plus/dist/index.css';

// i18n 配置
import { setupI18n, i18n } from './locales';

// SCSS 样式
import '@/assets/css/index.scss';

const app = createApp(App);

app.use(createPinia());
app.use(router);
setupI18n(app);

// Element Plus 多语言支持
const elementLocales: Record<string, any> = {
  'zh-CN': zhCn,
  'en-US': en,
  'ja-JP': ja,
};

app.use(ElementPlus, {
  locale: elementLocales[i18n.global.locale.value],
});

app.mount('#app');
```

**文件：** `src/components/Common/LanguageSwitch.vue`

```vue
<template>
  <el-dropdown trigger="click" @command="handleChangeLanguage">
    <span class="language-switch">
      <FontAwesomeIcon :icon="globe" class="mr-2" />
      {{ currentLanguageLabel }}
      <el-icon class="ml-1"><ChevronDown /></el-icon>
    </span>
    <template #dropdown>
      <el-dropdown-menu>
        <el-dropdown-item command="zh-CN" :disabled="currentLocale === 'zh-CN'">
          中文
        </el-dropdown-item>
        <el-dropdown-item command="en-US" :disabled="currentLocale === 'en-US'">
          English
        </el-dropdown-item>
        <el-dropdown-item command="ja-JP" :disabled="currentLocale === 'ja-JP'">
          日本語
        </el-dropdown-item>
      </el-dropdown-menu>
    </template>
  </el-dropdown>
</template>

<script setup lang="ts">
import { computed, watch } from 'vue';
import { useI18n } from 'vue-i18n';
import { globe } from '@fortawesome/free-solid-svg-icons';
import { FontAwesomeIcon } from '@fortawesome/vue-fontawesome';
import { ChevronDown } from '@element-plus/icons-vue';

const { locale } = useI18n();

const languageLabels: Record<string, string> = {
  'zh-CN': '中文',
  'en-US': 'English',
  'ja-JP': '日本語',
};

const currentLocale = computed(() => locale.value);
const currentLanguageLabel = computed(() => languageLabels[currentLocale.value]);

const handleChangeLanguage = (lang: string) => {
  locale.value = lang;
  localStorage.setItem('locale', lang);
  
  // 更新 Element Plus 语言
  import(`element-plus/es/locales/${lang === 'zh-CN' ? 'zhCn' : lang === 'en-US' ? 'en' : 'ja'}.mjs`)
    .then((module) => {
      // Element Plus 语言切换逻辑
    });
};

// 从 localStorage 恢复语言设置
const savedLocale = localStorage.getItem('locale');
if (savedLocale && ['zh-CN', 'en-US', 'ja-JP'].includes(savedLocale)) {
  locale.value = savedLocale;
}
</script>
```

## 5. 翻译文件管理最佳实践

### 5.1 文件组织策略

1. **按模块划分**：每个页面/组件对应独立的翻译文件
2. **通用内容抽取**：将重复使用的文本放入 `common.ts`
3. **命名空间隔离**：通过命名空间避免键冲突

### 5.2 翻译工作流程

```
1. 开发人员标记需要翻译的文本
2. 提取所有翻译键到翻译文件
3. 翻译人员填充各语言版本
4. 代码审查确保翻译完整性
5. 测试验证语言切换效果
```

### 5.3 工具辅助

**推荐 VS Code 扩展：**
- **i18n Ally**：实时预览翻译、自动提取翻译键
- **Localize**：批量翻译、翻译记忆库

## 7. 潜在挑战与解决方案

### 7.1 Element Plus 组件国际化

**挑战**：Element Plus 组件需要单独配置语言

**解决方案**：
```typescript
// 在语言切换时动态加载对应语言包
import(`element-plus/es/locales/${locale}.mjs`).then(module => {
  app.config.globalProperties.$ELEMENT = { locale: module.default };
});
```

### 7.2 动态内容翻译

**挑战**：问卷题目内容是用户创建的，无法提前翻译

**解决方案**：
- 问卷内容本身不翻译（属于用户数据）
- 仅翻译系统界面和提示文本

### 7.3 性能优化

**挑战**：大量翻译文件可能影响首屏加载

**解决方案**：
- 使用动态导入实现懒加载
- 配置 Vite 按需加载翻译文件

```typescript
// 懒加载示例
const loadLocaleMessages = async (locale: string) => {
  const messages = await import(`./${locale}/index.ts`);
  return messages.default;
};
```

### 7.4 TypeScript 类型支持

**挑战**：翻译键缺乏类型检查

**解决方案**：
- 使用 `type-safe-i18n` 或自定义类型
- 生成翻译键的类型定义文件

```typescript
// 类型定义示例
type TranslationKeys = 
  | 'common.title'
  | 'common.create'
  | 'header.save'
  | 'editor.question';
```

### 7.5 日期/数字格式化

**挑战**：不同语言的日期、数字格式不同

**解决方案**：
- 使用 `Intl` API 进行本地化格式化
- 封装格式化工具函数

```typescript
// 日期格式化
const formatDate = (date: Date, locale: string) => {
  return new Intl.DateTimeFormat(locale).format(date);
};

// 数字格式化
const formatNumber = (num: number, locale: string) => {
  return new Intl.NumberFormat(locale).format(num);
};
```

## 9. 代码安全性

### 9.1 XSS 防护

- 使用 `t()` 函数时自动转义 HTML
- 避免使用 `v-html` 渲染翻译内容

### 9.2 敏感信息保护

- 翻译文件不应包含敏感配置
- 使用环境变量管理敏感信息

### 9.3 资源加载安全

- 验证语言代码合法性
- 防止路径遍历攻击

```typescript
const validLocales = ['zh-CN', 'en-US', 'ja-JP'];
const loadLocale = (locale: string) => {
  if (!validLocales.includes(locale)) {
    throw new Error(`Invalid locale: ${locale}`);
  }
  // 加载翻译文件
};
```
