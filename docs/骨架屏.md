# 骨架屏方案文档

## 1. 骨架屏概述

骨架屏（Skeleton Screen）是一种页面加载状态的视觉占位符，用于在数据加载过程中提供视觉反馈，提升用户体验。与传统的加载指示器（如Spinner）相比，骨架屏能：

- 提前展示页面布局结构，减少用户等待焦虑
- 平滑过渡到最终内容，避免页面闪烁
- 提供更好的视觉连贯性，增强用户对页面结构的认知

## 2. Arco Design 骨架屏组件介绍

### 2.1 核心组件

Arco Design Vue 提供了一套完整的骨架屏组件，主要包括：

- `<a-skeleton>`：骨架屏容器组件，控制整体加载状态和动画
- `<a-skeleton-line>`：线型骨架组件，用于模拟文本、列表等线性内容
- `<a-skeleton-shape>`：图形骨架组件，用于模拟图片、图标、圆形头像等

### 2.2 API 参考

#### `<a-skeleton>` Props
| 参数名 | 描述 | 类型 | 默认值 |
|--------|------|------|--------|
| loading | 是否展示骨架屏（加载中状态） | boolean | true |
| animation | 是否开启骨架屏动画 | boolean | false |

#### `<a-skeleton-line>` Props
| 参数名 | 描述 | 类型 | 默认值 |
|--------|------|------|--------|
| rows | 展示的行数 | number | 1 |
| widths | 线型骨架的宽度，数组形式 | Array<number \| string> | [] |
| line-height | 线型骨架的行高 | number | 20 |
| line-spacing | 线型骨架的行间距 | number | 15 |

#### `<a-skeleton-shape>` Props
| 参数名 | 描述 | 类型 | 默认值 |
|--------|------|------|--------|
| shape | 图形骨架的形状 | 'square' \| 'circle' | 'square' |
| size | 图形骨架的大小 | 'small' \| 'medium' \| 'large' | 'medium' |

## 4. 骨架屏方案设计

### 4.1 方案架构

我们将采用组件化的方式实现骨架屏，包括：

1. **基础骨架屏组件**：基于 Arco Design 骨架屏组件封装的通用组件
2. **页面级骨架屏**：针对每个主要页面设计的特定骨架屏
3. **业务组件骨架屏**：针对复杂业务组件设计的骨架屏

### 4.2 目录结构设计

在 `app/frontend/src/components/` 目录下创建骨架屏相关组件：

```
src/components/
├── acro-icons.vue
└── skeletons/              # 骨架屏组件目录
    ├── BaseSkeleton.vue    # 基础骨架屏组件
    ├── HomeSkeleton.vue    # 首页骨架屏
    ├── AboutSkeleton.vue   # 关于页骨架屏
    ├── LoginSkeleton.vue   # 登录页骨架屏
    └── index.ts            # 骨架屏组件导出
```

### 4.3 实现策略

1. **统一管理加载状态**：使用 Vuex/Pinia 或组件内状态管理加载状态
2. **条件渲染**：使用 `v-if/v-else` 或骨架屏组件的 `loading` 属性控制骨架屏与真实内容的显示
3. **动画效果**：根据需要启用骨架屏动画，提升视觉体验
4. **响应式设计**：确保骨架屏在不同设备上都能正常显示

### 5.5 页面中使用骨架屏

以 `HomeView.vue` 为例，展示如何使用骨架屏：

```vue
<template>
  <div class="home-view">
    <HomeSkeleton :loading="loading" />
    
    <!-- 真实内容 -->
    <div v-if="!loading" class="home-content">
      <!-- 页面真实内容 -->
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue';
import { HomeSkeleton } from '@/components/skeletons';
import { fetchHomeData } from '@/apis/home';

const loading = ref(true);
const homeData = ref(null);

onMounted(async () => {
  try {
    // 模拟数据加载延迟
    await new Promise(resolve => setTimeout(resolve, 1000));
    homeData.value = await fetchHomeData();
  } catch (error) {
    console.error('Failed to fetch home data:', error);
  } finally {
    loading.value = false;
  }
});
</script>
```

## 6. 最佳实践

### 6.1 使用建议

1. **骨架屏与真实内容匹配**：确保骨架屏的结构和比例与真实内容尽可能一致，避免视觉跳跃
2. **合理使用动画**：骨架屏动画可以提升体验，但不要过度使用，避免分散用户注意力
3. **设置适当的加载状态**：根据数据加载时间决定是否使用骨架屏，对于极快的加载（<300ms），骨架屏可能反而会增加感知延迟
4. **统一设计语言**：在整个应用中保持骨架屏的设计风格一致，包括颜色、圆角、间距等

### 6.2 性能优化

1. **懒加载骨架屏**：对于复杂的骨架屏，可以考虑懒加载，减少初始加载时间
2. **减少DOM节点**：避免创建过多的骨架屏元素，保持结构简洁
3. **缓存骨架屏**：对于频繁访问的页面，可以缓存骨架屏组件实例

### 6.3 可访问性考虑

1. **提供加载状态反馈**：除了视觉反馈，还应为屏幕阅读器等辅助技术提供适当的加载状态信息
2. **设置适当的ARIA属性**：使用 `aria-busy` 和 `aria-live` 等属性增强可访问性

```vue
<template>
  <div :aria-busy="loading" aria-live="polite">
    <HomeSkeleton :loading="loading" />
    <!-- 真实内容 -->
  </div>
</template>
```

## 7. 扩展与维护

### 7.1 新增骨架屏

当需要为新页面或组件添加骨架屏时，可按照以下步骤进行：

1. 在 `src/components/skeletons/` 目录下创建新的骨架屏组件
2. 在 `index.ts` 中导出新组件
3. 在对应的页面或组件中使用新骨架屏

### 7.2 更新骨架屏

当页面结构发生变化时，需要同步更新对应的骨架屏：

1. 调整骨架屏的结构和布局，使其与新的页面结构匹配
2. 更新骨架屏的样式，确保视觉一致性
3. 测试骨架屏与真实内容的过渡效果

## 8. 总结

骨架屏是提升用户体验的有效手段，通过结合 Arco Design 的骨架屏组件和我们设计的方案，可以在当前项目中轻松实现优雅的加载状态。合理使用骨架屏可以：

- 提升用户对应用性能的感知
- 减少用户等待焦虑
- 增强应用的专业感和现代感

建议在项目中的主要页面和组件中逐步应用骨架屏，以获得最佳的用户体验效果。
