# 前端性能与交互体验优化清单（frontend）

## 目标与范围

- 目标：提升点击响应速度、界面流畅度与过渡动画自然感，并改善页面加载性能。
- 范围：仅进行性能与交互体验优化，不修改任何业务逻辑代码。

## 问题排查方法（建议用于复测）

1. **Lighthouse（Chrome DevTools）**
   - 关注指标：FCP、LCP、CLS、INP、TBT。
   - 分别在移动/桌面预设下执行，记录分数与关键指标。
2. **Performance 面板**
   - 录制典型用户路径（登录 → 列表 → 详情 → 返回）。
   - 观察 Long Task、JS 执行占比、Layout/Style 重计算频次。
3. **Network 面板**
   - 观察首屏关键资源（JS/CSS）体积、请求并发、缓存命中。
4. **Coverage 面板**
   - 检查首屏未使用的 JS/CSS 比例，为拆包策略提供依据。
5. **Vue Devtools**
   - 检查组件重渲染频率与渲染耗时热点。
6. **Rendering 面板（可选）**
   - 观察 FPS、强制同步布局、合成层（Compositing）情况。

## 已实施优化措施（不涉及业务逻辑）

1. **页面切换过渡动画**
   - 在根路由视图增加轻量淡入/上移过渡，缓解突兀切换。
2. **全局交互反馈与点击响应**
   - 为按钮/输入/链接等交互控件统一设置过渡曲线与时长，提升视觉舒适度。
   - 开启 `touch-action: manipulation` 以减少移动端点击延迟。
3. **减少动画对无障碍用户的影响**
   - 支持 `prefers-reduced-motion`，在系统偏好为“减少动画”时自动降级。
4. **内容区滚动体验优化**
   - 为内容区添加 `scrollbar-gutter: stable`，减少滚动条出现引起的布局抖动。
   - 使用 `overscroll-behavior: contain`，降低滚动链影响范围。
5. **构建产物拆包与缓存友好**
   - 将 Vue 核心、UI 库与业务引擎拆分为稳定 chunk，提高缓存复用与首屏加载效率。

## 实施步骤（已完成）

1. App 根路由增加轻量过渡动画。
2. 全局样式加入统一过渡参数、交互点击优化与无动画偏好支持。
3. 布局内容区增加滚动稳定与滚动行为优化。
4. Vite 构建配置增加手动拆包策略，优化缓存与首屏加载。

3. 使用 Performance 录制关键路径，确认 Long Task 是否下降、INP 是否改善。
