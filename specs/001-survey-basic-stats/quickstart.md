# Quickstart: 问卷答卷基础统计

## 前置条件

1. `q-server` 运行中（后端 API 可用）
2. `app/frontend` 开发服务器运行中（`pnpm --filter frontend dev`）
3. 数据库中至少有一份已发布的问卷和若干答卷记录
4. 以管理员身份登录管理后台

## 验证步骤

### 1. 平台汇总仪表盘（已有功能）

- 登录后台，确认 `/dashboard` 页面展示了统计指标卡片（累计答卷、已发布问卷、今日/本周新增）
- 确认近 7 日趋势图正常显示

### 2. 统计列表页

- 导航到 `/survey-management/statistics`
- 确认已发布问卷列表正常显示，含答卷数列
- 点击某问卷的「统计详情」按钮

### 3. 单问卷统计详情页（新功能验证入口）

- 确认能正常跳转到 `/survey-management/statistics/{id}`
- 验证逐题统计：
  - 选择题 → 选项分布条形图 + 百分比
  - 评分题 → 平均值/最值 + 分值分布直方图
  - 文本题 → 最近 10 条原文抽样 + 空值率
  - 矩阵题 → 行列交叉表
  - 签名题 → 有/无签名计数
  - 展示型组件（text-note）不出现统计条目
- 验证无答卷时显示"暂无数据"
- 验证 404 场景（无效问卷 ID）

### 4. CSV 导出

- 在统计详情页点击「导出 CSV」
- 确认浏览器下载了 CSV 文件
- 用 Excel 打开验证中文正常显示
- 验证多选答案用分号分隔
- 验证问卷无答卷时导出内容为"暂无答卷数据"
